# Our World — آية علي

Personal cinematic engagement-gift website (Phase 1: static React + Vite).

## Stack

- React 19 + TypeScript + Vite
- Content kept in `src/data/` (separate from UI)
- No backend / Firebase in Phase 1

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```

## Workflow

See `PROJECT_SPEC.md`. Build one scene at a time after owner approval.
